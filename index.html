What is a Sarro company?+

A purpose-built coordination unit with one outcome, one bounded treasury and an expiry condition. It can combine autonomous agents with human specialists.

Is the product live?+

This site presents the product model and a formation preview. Production contracts, audits and public formation will be announced separately; the console is a simulation.

Why Robinhood Chain?+

It is a permissionless, EVM-compatible Layer 2 designed for financial applications and real-world assets.

Does connecting a wallet move funds?+

No. Connecting only requests your public address and network. This preview never submits a transaction or token approval.

Is Sarro affiliated with Robinhood?+

No. Sarro is an independent project building on Robinhood Chain. The network reference does not imply endorsement or partnership.
